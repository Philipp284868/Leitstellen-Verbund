# Einstieg

Benötigt werden ein Desktop-PC, Maus/Tastatur, ein aktueller Chromium- oder Firefox-Browser und eine Verbindung zum eigenen Spielserver. Referenzgrößen sind 1920×1080, 2560×1440, 1366×768 und 3440×1440. Unter 1100×650 zeigt das Spiel einen Hinweis statt einer mobilen Oberfläche. Browser-Zoom und Fenstergröße bleiben frei wählbar; entsprechend genügend Darstellungsfläche vorsehen.

Der Browser installiert keinen eigenen Spielserver. Ein Betreiber stellt Node.js 24 und eine dauerhafte SQLite-Datenablage bereit. Ein einzelner Disponent darf allein auf diesem Multiplayer-Server spielen. GitHub-Konto, Kartenabonnement und externer Audiodienst werden zum Spielen nicht benötigt.

Es handelt sich um eine fiktive Simulation, nicht um reale Einsatzplanung.
