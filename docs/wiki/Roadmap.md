# Bekannte Grenzen und Roadmap

- Keine fotorealistische 3D-/Satellitenkarte; echte stilisierte Spielwelt.
- Kein globaler Serverbrowser; Beitritt über die Adresse des Betreibers.
- Keine frei konfigurierbare Hierarchie feiner Disponentenrollen; Inhaber/Mitglieder gemäß aktuellem Modell.
- Kein separater frei startbarer Szenario-Spielmodus; der Einsatzkatalog ist eine Informationsansicht.
- Keine Smartphone-/Tablet-Produktoberfläche, keine lokale Offline-Simulation.
- GitHub Projects benötigt read:project/project-Rechte; ein fehlender API-Scope ist kein eingerichtetes Board.
- Die echte Wiki benötigt gegebenenfalls die erste manuell angelegte Seite, bevor das separate Wiki-Git-Repository erreichbar ist.

Konkrete offene Arbeiten stehen in [Issues](https://github.com/Philipp284868/Leitstellen-Verbund/issues). [Ideen](https://github.com/Philipp284868/Leitstellen-Verbund/discussions/25) sind noch keine zugesagten Funktionen oder Termine.
