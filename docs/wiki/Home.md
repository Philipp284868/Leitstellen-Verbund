# Leitstellen-Verbund

PC-Multiplayer in Deutschland. Notrufe bearbeiten, eigene und berechtigt gemeinsame Einsätze koordinieren, Fahrzeuge und Funk verfolgen. Das Spiel läuft serverseitig in Echtzeit.

Die aktuelle Version steht im [Changelog](https://github.com/Philipp284868/Leitstellen-Verbund/blob/main/CHANGELOG.md). Eine private Installation kann noch einen älteren freigegebenen Stand verwenden. Reguläre Updates erhalten Fortschritt; ein einmaliger vollständiger Reset ist eine getrennte bestätigte Betreiberaktion.
